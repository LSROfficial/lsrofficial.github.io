# LSROfficial 的 GitHub Pages 个人主页

这是部署在 `https://lsrofficial.github.io` 的个人网站。

## 本地预览

直接用浏览器打开 `index.html` 即可预览。

## 推送上线

```bash
git init
git add .
git commit -m "init github pages"
git branch -M main
git remote add origin https://github.com/LSROfficial/lsrofficial.github.io.git
git push -u origin main
```

推送后访问 `https://lsrofficial.github.io` 即可看到主页。
（GitHub Pages 首次部署可能需要等待几分钟。）

## 自定义

- 修改 `index.html` 中的名字、自我介绍和项目链接。
- 修改 `style.css` 调整配色和样式。
